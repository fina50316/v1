## Google Maps 設定（必要）
1. 到 Google Cloud Console 建立或選擇專案，設定帳單帳戶。
2. 啟用 **Maps JavaScript API** 與 **Directions API**。
3. 建立 API Key，建議設定網站 HTTP Referrer 限制（例如 localhost 與正式網域），並限制可使用的 API。
4. 開啟 `js/google-maps-config.js`，將 `YOUR_GOOGLE_MAPS_API_KEY` 替換成自己的金鑰。
5. 透過 Apache / XAMPP 或正式網站網域開啟頁面。不要使用 `file://`。

**安全提醒：** API Key 會出現在瀏覽器端，請務必設定 HTTP Referrer 與 API 限制；不要使用不受限制的金鑰。

## 開發環境
- PHP 8.x（XAMPP）
- MariaDB / MySQL
- Apache

## 本機啟動
1. 將專案放入 XAMPP 的 `htdocs/v1`。
2. 啟動 Apache 與 MySQL。
3. 依需求匯入 `database/kiwi_trails.sql`。
4. 確認 `php/database.php` 的資料庫連線設定。
5. 設定 Google Maps API Key 後，開啟 `http://localhost/v1/index.html`。
