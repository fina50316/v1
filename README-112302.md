# KIWI TRAILS 112302

## 開發環境
- PHP 8.x（XAMPP）
- MariaDB / MySQL
- Apache

## 安裝
1. 將此專案放到 XAMPP 的 `htdocs/v1`。
2. 啟動 Apache 與 MySQL。
3. 開啟 phpMyAdmin，匯入 `database/kiwi_trails.sql`。
4. 確認 `php/database.php` 的主機、資料庫名稱、帳號及密碼符合本機設定。
5. 以 `http://localhost/v1/index.html` 開啟網站。不要直接用 file:// 開啟 PHP 功能。

## 已串接
- 會員註冊：`php/register.php`，密碼以 `password_hash()` 儲存。
- 會員登入／登出：`php/login.php`、`php/logout.php`，使用 PHP Session。
- 留言新增：`php/message_add.php`。
- 展示訂單：`php/order_create.php`，需登入會員；不含金流。
- 消息詳細頁：`news-detail.php?id=消息ID`，資料來自 news 資料表。
- 商品加入購物車：前端 localStorage 暫存，結帳時送 PHP 建立資料庫訂單。

## 管理員
匯入資料庫後，先註冊一般會員，再在 phpMyAdmin 執行：
`UPDATE members SET role='admin' WHERE email='你的管理員Email';`
管理後台尚需完成管理員登入保護及各項新增／編輯／刪除介面；目前此版本先完成核心前台資料流程。

## 注意
- 商品範例價格目前設為 0，請在 products 資料表設定實際展示價格後，再同步前端商品卡片的 data-price。
- 此版本尚未進行正式主機安全設定；上線前需更換資料庫帳密、啟用 HTTPS、加上 CSRF 防護及登入頻率限制。
